# Hytale Name Finder

Generate Hytale username ideas and check which ones nobody is using yet.

**[Open it →](https://luciotd.github.io/hytale-name-finder/)**

One HTML file. No install, no build, no account.

## Use

- **Generate** names: made-up words, real words, two words combined, a pattern like `Lu???`, or random characters.
- **My list**: paste your own names and check them all at once.
- Free names sort to the top. Click one to copy it.

To run it locally, download `index.html` and open it in a browser.

## How it works

Each name is looked up through [PlayerDB](https://playerdb.co)'s open Hytale API, a few per second, and results are cached in your browser for six hours.

"Free" means no player has that name. Hytale also blocks some reserved and filtered names, which a lookup can't see, so confirm at [accounts.hytale.com](https://accounts.hytale.com) before getting attached to one.
